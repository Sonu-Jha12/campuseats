# CampusEats

CampusEats is a web services project developed as part of the CSS43 Web Services assignment.

## Project Work

This repository contains practical work on HTTP requests, HTTP responses, and browser network analysis.

## Repository Structure

- `docs/http-log.md` — Contains five HTTP request/response examples made using curl, including a deliberate 404 request.
- `docs/network-analysis.md` — Contains browser DevTools Network analysis, including request count, page size, slowest resource, and observed 3xx/4xx responses.
- `docs/brief.md` — Contains a one-page description of the CampusEats system.

## Tools Used

- curl
- Google Chrome DevTools
- Git
- Markdown

## HTTP API

The HTTP request experiments used the JSONPlaceholder public read-only JSON API.
